# Format and Delivery

1. Resolve the destination shape, frame size, active timeline range, export settings, subtitle bounds and important subjects. Inspect representative wide and tight frames for a requested crop.
2. Recommend a native export preset by ID: `reels-1080`, `shorts-1080` or `tiktok-1080` for 1080×1920; `instagram-feed-4x5` for 1080×1350; `square-1080` for 1080×1080; `youtube-1080` for 1920×1080; or `landscape-4k`, `high-bitrate`, `social-h264-aac` and `custom` when their output settings fit the request.
3. Prepare a crop or reframe only when the active editor exposes the operation. Keep text inside the intended safe area and report any subject loss. Use the native export UI to select a format preset.
4. Use `verify-deliverable` only when the recipe runtime reports it available and the encoded artifact can be read. In the current editor recipe runtime, composition capture and encoded-output verification are unavailable; an ordinary preview does not prove encoded-output properties.
5. Report separately what the project preview shows and what the decoded export confirms. Claim frame size, text legibility or retained audio only after checking the exported artifact for that property. Recheck the project revision before staging any edit for approval.
