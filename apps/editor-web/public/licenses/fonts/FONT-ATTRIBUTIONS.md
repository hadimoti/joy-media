files are redistributed under the SIL Open Font License 1.1, reproduced in

- `@fontsource-variable/inter@5.2.6` — Inter Variable — Copyright Google Inc.
- `@fontsource-variable/vazirmatn@5.2.6` — Vazirmatn — Copyright Google Inc.
- `@fontsource/noto-sans-arabic@5.2.6` — Noto Sans Arabic — Copyright Google Inc.
- `@fontsource/noto-naskh-arabic@5.2.6` — Noto Naskh Arabic — Copyright Google Inc.

These are the only editor font files. The legacy login-gate font files were
removed and are not part of the application artifact.
