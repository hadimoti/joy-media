## Decision legend

- **Keep main-native**: already reconciled on a main-based branch; retain after rerunning the final
  gate.
- **Port behavior**: reimplement/cherry-pick only the named contract onto the main-based finish line,
  resolving conflicts through tests rather than commit ancestry.
- **Combine**: both lines contain useful coupled behavior; one shared contract is required.
- **Keep hidden**: not a 1.0 defect while genuinely absent from production navigation and promises.
- **Reject as evidence**: useful diagnostic, but cannot satisfy a release gate.
