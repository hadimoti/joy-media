workflows.

same change. Evidence for every required row must match the same candidate SHA and pass first try
with zero retries.

## Required acceptance gate

The release evidence must contain passing first-attempt results with zero retries for:

1. `cli.render.playable`
2. `cli.render.unsupported-features`
3. `cli.render.failure-recovery`
4. `cli.render.windows-entrypoints`
5. `project.persistence.fresh-process`
6. `desktop.app.restart-save-export`
7. `desktop.windows.installed-lifecycle`
8. `desktop.export-media-semantics`
9. `release.exact-candidate-two-pass`

`release.exact-candidate-two-pass` is evaluated by the existing
`.github/workflows/release-candidate-v2.yml` exact-source two-pass gate. A successful source
build, worker self-test, browser-only export, plan manifest, skipped required scenario, or
unsigned staging package does not satisfy these rows. The owner-confirmed CLI requirement is a
playable file that FFprobe can inspect and a decoder can read; a render-plan manifest alone is
not sufficient.
