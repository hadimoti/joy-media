## 1. How to read and run this checklist

### 1.1 Purpose

This document provides the definitive, granular checklist for the live acceptance pass of every editing, timeline, monitor, drag-and-drop, format, and header menu tool in JOY Media v1.1.1.

During session S31 (task T-L03), Claude Code executes each verified tool through Windows-MCP exactly as a human editor would, verifies the observable behavior on screen, records a screenshot under `C:\jgp\v111\evidence\T-L03\`, and marks the result as `pass` or `fail`. Features that are not yet built or merged are marked `NOT BUILT (needs T-xx)` and skipped by the live pass. Any failure is logged with a defect ID in `docs/qa/v1.1.1/DEFECTS.md` and routed to the appropriate helper lane.

### 1.2 Pre-flight setup and data safety protocol (task T-L03)

Every live test run must strictly follow section 0 of `03-TASK-CARDS.md`:

1. **Never touch:** The owner's real data folders (`joy-media-assets`, `AppData\Roaming\@joy-media`, `Documents\JOY Projects`) are strictly forbidden. Never read, write, or point the app at them.
2. **Scratch profile:** The app must be launched with `--user-data-dir` set to an isolated directory under `C:\jgp\v111\<agent>\profiles\` (e.g. `C:\jgp\v111\cc\profiles\`).
3. **Scratch library:** Before importing any media, the tester must open **Edit > Asset Library Folder…** and point the library at an empty scratch folder under `C:\jgp\v111\` (e.g. `C:\jgp\v111\scratch-library\`).
4. **Library file count:** Count files in the owner's library folder before and after the test run; the count must remain unchanged.
5. **Lock file:** Maintain the active lock file `C:\jgp\LOCK-app-run.txt` with runner name, timestamp, and purpose.
6. **Registry check:** Export `HKCU\Software\Classes\joy` and verify SHA-256 equals `AF05BE55222C86FECE27E738B7E8A931CB4261C9797261C67DDE3C71A4E5CAC0` before and after launch.
7. **Test media:**
   - Visual media: Source test clips and images are taken from `C:\jgp\ui-shots-20261112\media-final\` (`Northern lights.mp4`, `Golden hour.mp4`, `Soft light.mp4`, `Alpine lake.png`, `Turquoise sunset.png`, `Autumn path.png`, `Neon rain.png`).
   - Audio media: Since `media-final` contains no standalone audio, audio rows use the verified fixture files from `C:\jgp\v111\fixtures\` (e.g. `audio-stereo.wav` or `audio-silent.wav`, authored in T-A04).
   - Drag and drop: Drag rows must drag COPIES placed in `C:\jgp\v111\dnd\` (never the originals).
8. **Export location:** Output video files from **Export MP4** default to `joy-media-export-<timestamp>.mp4` in the user downloads/desktop directory or chosen target path (e.g. `C:\jgp\v111\evidence\T-L03\export.mp4`).

   - Checklist row ID (e.g. `LTP-026`)
   - Exact observed behavior vs expected behavior
   - Severity and owning task / agent
3. The defect ID is written into the **Defect ID** column of this checklist.
4. Following the fix and merge of the owning card, the failed row is re-run along with 10 randomly selected passed rows.
5. Task T-L03 closes only when a complete verification run of all active rows completes with **zero failures**.
