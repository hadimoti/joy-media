# Feature Status

Audited against current source on 2026-09-05.

This ledger records source-mounted feature availability only. It does not replace
release-gate evidence, authenticated browser verification, or deployment
readiness checks.

Workflow acceptance update: pending bundled-workflow approvals are saved in
this browser with a project ID, canonical revision, and validated checkpoint.
The Workflows panel lists saved approvals for the current project, supports
review/discard, and rejects resume after a project change. Storage failure is
reported as session-only recovery. Unit tests exercise reload at both approval
stages, completed-node reuse, malformed records, and project isolation. This
does not turn fixture/deferred recipe outputs into finished media exports.
See [workflow recovery scope](workflow-recovery.md) for remaining limits.
